A Browser-Native, Interactive Electronic Circuit Simulator built with Vanilla JavaScript and HTML5 Canvas.
🚀 Synopsis
This project is a high-precision, interactive tool designed for the design, verification, and educational visualization of electronic circuits
. Unlike traditional simulators that require plugins or external software, this application runs entirely in the browser using a custom numerical engine built from the ground up
.
The core mission is to bridge the gap between abstract circuit theory and intuitive visual learning. By combining a detailed transistor-level description of circuits with a native web stack, users can build, test, and monitor electrical systems in real-time
.
🧠 Mathematical & Numerical Engine
The simulator’s reliability is rooted in professional-grade circuit simulation principles:
Modified Nodal Analysis (MNA): The engine systematically formulates circuit equations by identifying nodes and constructing a system matrix to solve for unknown voltages and currents
.
Linear Solver: Employs LU Decomposition with Partial Pivoting to ensure numerical stability when solving the MNA matrix
.
Transient Analysis: Uses numerical integration techniques (such as the Trapezoidal Rule or Backward Euler) to compute time-varying behavior for dynamic elements like capacitors and inductors
.
✨ Key Features (Initial Phase)
Interactive Schematic Capture: A native HTML5 Canvas interface allows users to place and connect components via drag-and-drop functionality
.
Real-Time Visualization: Animated current flow (moving dots) and color-coded voltage levels provide immediate feedback on circuit behavior
.
Component Library: Initial support for linear passives (resistors, capacitors) and ideal voltage sources
.
Virtual Oscilloscope: Integrated time-domain graphing to monitor waveforms at any node
.
🛠 Tech Stack
Frontend: HTML5 (Canvas API), CSS3 (Responsive UI).
Logic: Vanilla JavaScript (ES6+) for the mathematical solver and event-driven interactivity
.
Data Structures: Efficient linked-list or JSON-based records for circuit netlists and compressed-column formats for matrix operations
.
🗺 Roadmap
Phase 1: Core linear DC solver and basic Canvas UI
.
Phase 2: Implementation of Transient Analysis for time-domain waveforms
.
Phase 3: Support for nonlinear devices (diodes and transistors) using Newton-Raphson iteration
.
Phase 4: Educational "Matrix Mode" to show intermediate MNA assembly steps
.
